打开 GitHub 发布页，在 Assets（附件）中点击 `ElysiaDesktopPet-1.5.9.24-Setup.exe` 下载，再双击安装。夸克中的文件名为 `爱丽希雅桌宠-1.5.9.24-安装.exe`。`Source code` 两项是 GitHub 自动附带的仓库文件，不是安装包。
