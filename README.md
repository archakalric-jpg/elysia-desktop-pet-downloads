# 爱丽希雅桌宠 V2

这是一款个人制作的**非官方《崩坏3》同人桌宠**，不代表游戏官方。角色及相关设定的权利归原权利人。免费提供。

**已实测系统：** Windows 11 家庭版（64 位）。Windows 10 及其他 Windows 版本尚未实测。

**[GitHub 下载](https://github.com/archakalric-jpg/elysia-desktop-pet-downloads/releases/latest)** · **[夸克网盘下载](https://pan.quark.cn/s/a1fdf7635cb1)**

**[问题与建议反馈](https://github.com/archakalric-jpg/elysia-desktop-pet-downloads/issues)**：登录 GitHub 后点击 **New issue**，填写标题和内容即可。

打开 GitHub 发布页，点击顶部的“下载 Windows 安装包 · 117 MB”下载，再双击安装。夸克中的文件名为 `爱丽希雅桌宠-1.5.9.24-安装.exe`。`Source code` 两项是 GitHub 自动附带的仓库文件，不是安装包。

安装前请退出正在运行的旧桌宠；以后下载新版安装包，选择原二代安装位置即可更新并保留资料。从一代接续时，按首次提示手动选择旧资料文件夹。

**装好之后怎么用：**

- **启动：** 双击桌面上的“爱丽希雅桌宠 V2”快捷方式，也可从开始菜单找到它。
- **打开设置：** 在任务栏右下角右键桌宠图标，选择“桌宠设置…”；图标隐藏时，先展开托盘的上箭头。
- **完全退出：** 右键同一个托盘图标，选择“退出”。

发布页附有完整使用说明与 SHA-256 校验文件。安装包未做数字签名，也未附带游戏原声。

本仓库只提供公开安装包和说明，程序源码保存在独立私有仓库。个人资料和备份不在这里发布。
